# SDD — Módulo de Recomendação (versão oficial)

Planejamento Spec-Driven Development do módulo de recomendação do Origem (EP8 / HU15),
**na versão entregue em 17/09/2026** na disciplina de Projeto 4.

| Arquivo | Conteúdo |
|---|---|
| [`product.md`](product.md) | contexto de negócio, público e limites |
| [`requirements.md`](requirements.md) | requisitos RF-01..RF-08 e RNF-01..RNF-07, critérios de aceitação em EARS |
| [`design.md`](design.md) | componentes, fluxo de dados, modelo de dados e interface de integração |
| [`tasks.md`](tasks.md) | tarefas de implementação rastreadas aos requisitos |

A implementação está em [`ia-recomendacao/`](../../ia-recomendacao/) e segue o contrato de `design.md`
(por exemplo, a resposta `{ produtoReferenciaId, recomendacoes }`).
A pasta [`docs/modulo-recomendacao/`](../modulo-recomendacao/) é uma versão de trabalho anterior, mantida só como histórico.
